# team-task-manager
An App built for Drive Assesment

Team Task Manager

Features:
- User authentication (JWT)
- Project creation
- Task assignment
- Task status tracking
- Dashboard (total, pending, completed, overdue)

Tech:
- Node.js
- Express
- MongoDB
- Railway deployment

Steps to run:
1. npm install
2. add .env
3. npm run dev
